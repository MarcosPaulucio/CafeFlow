SEGURANÇA DOS DADOS

Backup e restauração

Exporte clientes e serviços para guardar uma cópia fora do navegador.

Salvar backup

Baixe um arquivo JSON com seus dados e a cotação salva.

Guarde o arquivo em um local seguro, como OneDrive, Google Drive ou um pendrive. O backup contém dados pessoais dos clientes.

Restaurar backup

Selecione um arquivo JSON exportado pelo CafeFlow.

Na mesclagem, os registros atuais têm prioridade quando o ID já existe.

O envio à nuvem é separado da restauração local, exige confirmação e fica disponível ao entrar na conta do estabelecimento. Ele sempre mescla e preserva os dados locais com o mesmo ID, mesmo se a opção acima estiver em “Substituir”.

A restauração só é executada após selecionar um arquivo válido e confirmar a ação.
